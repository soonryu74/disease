# ⑤ 감염병 질병정보 도감 (실제 내용)

"법·제도 연혁"만이 아니라 **감염병 자체의 실제 내용**(병원체·감염경로·잠복기·증상·진단·치료·예방·신고)을 급별로 정리한다. 모든 내용은 **질병관리청 공식 자료**(감염병포털·감염병누리집·국가건강정보포털·예방접종도우미·병원체생물안전정보)에서 수집·교차확인했다.

> ⚠️ 참고용. 진단·치료는 반드시 의료진·보건소 확인. 잠복기 등 일부 수치는 KDCA 명시값 미확정 시 '미확인'/통상범위로 표기.

## 표준 항목 (질병별 공통 서식)
- 법정 급수 / 신고기한
- 병원체 (정확한 학명)
- 감염경로 (매개체 포함)
- 잠복기
- 주요 증상
- 진단
- 치료 (치료제·백신 유무)
- 예방 (예방접종 대상 여부)
- 특징 / 역사·옛이름 메모
