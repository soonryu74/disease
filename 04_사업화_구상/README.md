# ④ 사업화 구상 — 감염병 지식 서비스

§01~03에서 구축하는 **정제된 감염병 지식베이스**(법령 연혁 + 지침 + 백서 통계)를 자산으로,
전문가용·일반인용 정보 서비스를 사업화하는 구상.

---

## 1. 핵심 자산 (Moat)

우리가 이미 만들고 있는 것 = 남이 쉽게 못 만드는 것.

1. **법령 연혁 구조화 DB** — 1954~현재 67개 버전, 조문 단위 변천(§01, 법제처 API 기반, 자동 갱신)
2. **지침 정제·검수 코퍼스** — 오탈자·용어·법령정합성까지 검수된 실무지침(§02)
3. **백서 시계열 통계** — 연도별 감염병 발생·대응 지표 통합(§03)
4. **버전 추적 파이프라인** — 법·지침이 바뀌면 자동 감지·알림 (재현 가능한 수집기 §90)

> 정부 자료는 '흩어져 있고, 형식이 제각각이고, 최신본 찾기 어렵다'.
> **"정확·최신·연결(법↔지침↔통계)"** 이 우리의 차별점.

---

## 2. 두 갈래 시장

### A. 전문가용 (B2B / B2G) — 유료
| 고객 | 니즈 | 우리 제품 |
|---|---|---|
| 병원 감염관리실·감염내과 | 최신 신고기준·격리기준, 지침 개정 추적 | **지침/법령 변경 알림 + 근거 링크** 구독 |
| 보건소·지자체 감염병관리단 | 법정감염병 대응 표준업무 | 대응 체크리스트·서식 자동화 |
| 제약·진단·백신 기업, 로펌 | 규제 연혁·인허가 근거 | 조문 단위 연혁 검색 API |
| 연구자·역학조사관 | 백서/통계 시계열 | 정제 데이터셋·API |

**수익모델**: SaaS 구독(월정액) · 데이터 API 종량제 · 기관 라이선스 · 리서치 리포트 판매

### B. 일반인용 (B2C) — 무료+프리미엄
| 고객 | 니즈 | 우리 제품 |
|---|---|---|
| 학부모·보호자 | "이 병 신고 대상? 등교 중지?" | 감염병 쉬운 설명 + 대응 가이드 |
| 여행자 | 해외감염병·예방접종 | 여행지별 감염병 브리핑 |
| 일반 시민 | 유행 시 신뢰할 정보 | 팩트체크된 감염병 Q&A(챗봇) |

**수익모델**: 광고·제휴(여행보험·예방접종 예약) · 프리미엄(개인 알림·PDF) · 공공/공익 후원

## 3. 제품 형태 (단계별)

```
1단계  정적 지식 사이트/아티팩트  ── 법령연혁·용어·분류 한눈에 (이미 §01에서 시작)
2단계  검색 + 변경 알림 서비스     ── "내 관심 감염병/지침 바뀌면 알림"
3단계  RAG 챗봇 (전문가/일반 모드)  ── 정제 코퍼스 기반, 출처 링크 필수
4단계  데이터 API / 오픈 데이터셋   ── B2B·연구자 대상 유료 API
```

---

## 4. 차별화 원칙 (신뢰가 곧 상품)

- **출처 100% 링크** — 모든 답변에 법제처/질병관리청 원문 링크. 환각 방지.
- **최신성 자동화** — §90 파이프라인으로 법·지침 개정 자동 반영.
- **전문가 모드 / 일반인 모드 분리** — 같은 사실, 다른 언어 수준.
- **공적 사실은 무료** — 신뢰·트래픽 확보. 유료는 '편의·속도·자동화·API'에 매김.

## 5. 리스크 & 준수사항

| 리스크 | 대응 |
|---|---|
| 의료정보 = 오정보 시 피해 | 진단·처방 아님 명시, "반드시 의료진·보건소 확인" 고지, 출처 링크 |
| 저작권/이용약관 | 공공누리(KOGL) 유형 확인. 법령은 자유이용, 백서·지침은 출처표기·상업이용 조건 확인 필수 |
| 정부 무료 서비스와 경쟁 | 우리는 '통합·추적·자동화·API'로 차별(원문 재판매 아님) |
| 데이터 최신성 | 자동 수집 + 개정일 검증 + **as-of 스냅샷 규칙** |
| **낙인·차별**(매독·HIV 등) | 질병정보 표현 수위 원칙, 감시 확대의 프라이버시 영향 병기, 익명검진 안내 |
| **검색기록 = 민감정보** | 이용자 질병 검색이력은 개인정보 보호법 제23조 민감정보 취급 — 비식별·최소수집 설계 필수 |
