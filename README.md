# 대한민국 감염병 자료 아카이브 (질병관리청 기반)

질병관리청(KDCA)·법제처 감염병 관련 자료를 **정확·최신·연결** 원칙으로 정리하고,
이를 지식 서비스로 사업화하기 위한 통합 저장소.

> 모든 사실은 **공식 1차 출처(법제처 국가법령정보 · 질병관리청)** 에서 직접 수집·검증한다.

## 지금까지의 핵심 성과

1. **법제처 국가법령정보 공동활용 Open API 검증 완료**
   - "대한민국 법률 전부 정리 API"로 가능 ✅ / **연도별(연혁)은 별도 target(`eflaw`)** ✅
   - 감염병예방법 = 법령ID `001792`, **67개 시행 버전(1954→2026)** 전량 수집
2. **감염병예방법 연혁 1차 정리 완료** — 제정→전부개정→급체계 개편까지 마일스톤·용어·분류·개수
3. **재현 가능한 수집 파이프라인** — 누구나 스크립트로 최신 데이터 갱신 가능
