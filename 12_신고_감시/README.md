# ⑫ 신고 감시 — 의사가 신고한 수

⑩ 진단검사 감시(병원체를 직접 본 숫자)의 짝. 「주간 건강과 질병」 부록의 **환자감시** 표를 시계열로 복원한다. 두 축을 겹치는 분석은 [⑬ 교차검증](../13_교차검증/README.md)에 있다.

## 수록

PHWR 17~19권 **36개 호**. 전수감시 표는 호마다 **금주 1주치**만 실리므로(병원체감시는 4주치) 이 축은 **4주 간격 표본**이다 — 2023년 52주 ~ 2026년 35주, 36개 주차.

## 읽을 때 주의

1. **표기가 바뀐다.** CRE는 3년 사이 '카바페넴내성장내세균 속균종' → '장내세균목' → 띄어쓰기 변형으로 세 번 바뀌었다. 표기 그대로 집계하면 한 질병이 세 계열로 쪼개진다. 이 저장소는 정식 명칭으로 합치고 변경 사실을 `표기_원장.json`에 남긴다.
2. **신규 편입 질병은 열 수가 다르다.** 매독·엠폭스는 '5년 주별 평균' 칸이 비어 있어 추출 열이 적다. 위치가 확정적인 **앞 두 칸(금주·누계)만** 채우고 나머지는 비운다(`열부분추출=Y`). 추정하지 않는다.
3. **5년 주별 평균의 정의** — 최근 5년 해당 주와 앞뒤 2주, 총 25주의 평균이다(원문 각주). 단순 같은 주 평균이 아니다.
4. **잠정통계다.** 최근 주차일수록 나중에 바뀐다.
