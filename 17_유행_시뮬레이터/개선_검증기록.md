## 3. 계산이 달라진 부분과 그 크기

두 가지를 바꿨고 둘 다 **기존 값을 재현하는 것을 목표로 삼지 않았다.**

**(1) 적분 방식 — 전진 오일러 → 4차 룽게–쿠타**

기존은 `dt=0.25` 고정 오일러였다. 홍역처럼 전파가 빠른 병에서 칸 크기를 줄이면 정점이 계속 움직였다(6761 → 6766, 0.07%p 넘게). 어느 칸이 맞는지 알 수 없는 상태였다.

룽게–쿠타로 바꾼 뒤에는 `dt` 0.25 와 0.01 의 결과가 소수 셋째 자리까지 같다.

```
요청 dt 0.25 → 정점 6765.688 · 누적 99987.647
요청 dt 0.01 → 정점 6765.688 · 누적 99987.647
```

**(2) 처음 유효재생산수의 정의**

기존은 첫 감염자를 빼기 전의 S 를 썼다. 실제 초기 S(0) = N − 보호 인구 − I0 로 바꿨다.
기본값(N=100,000 · I0=10)에서 차이는 **−0.010%**다.

**대표 시나리오 비교 (기존 → 새것)**

| 시나리오 | 누적 감염 차이 | 처음 Reff 차이 |
|---|---|---|
| 홍역 A (기본) | −0.003% | −0.010% |
| 홍역 B (격리 3일) | −0.001% | −0.010% |
| 백일해 A | −0.038% | −0.010% |
| 백일해 B (보호 80%) | +0.082% | −0.036% |
| 메르스 A·B | −0.001% 이하 | −0.010% |
| 코로나19 A | −0.137% | −0.010% |
| 인플루엔자 A·B | +0.034% | −0.010% |
| 에볼라 B (격리 5일) | **+0.340%** | −0.010% |

가장 큰 차이가 0.34%다. 전부 적분 오차가 줄어든 결과이고 모형의 가정은 바뀌지 않았다.

## 4. 새로 만든 것

- **집단 상태 화면** — S/E/I/R 를 점 300개로 그린다. 최대잔여법이라 합계는 늘 300이다.
  점 1개 ≈ 인구/300 임을 화면에 적는다. 점은 고정 자리에 있고 상태만 바뀐다.
  **개인을 따라가지 않고 접촉선·이동을 그리지 않는다.**
- **공통 재생** — 재생/멈춤/처음으로, 0.5·1·2·4배속, 날짜 슬라이더.
  A·B·그래프 세로선이 같은 날짜를 본다. 끝나면 자동으로 멈춘다.
  탭이 가려지면 멈추고, 한 프레임의 경과 시간에 상한을 둬 돌아왔을 때 건너뛰지 않는다.
- **조건 변경 처리** — 바뀌면 멈추고 0일로 되돌린 뒤 전체를 **한 번** 다시 계산하고
  “조건이 바뀌어 처음부터 다시 계산했습니다”를 띄운다. 재생은 만들어 둔 기록만 읽는다.
- **선택 날짜 비교표** — 누적·그날 새 감염·현재 I·현재 E, B−A 인원과 %.
  A=0 이면 %는 “계산 불가”로 적는다. 정점은 ‘하루 새 감염의 최대’라고 밝힌다.
  관찰 끝에 E+I 가 남으면 ‘관찰 종료 · 유행 진행 중’으로 적는다.
- **가져가기** — PNG(점 그림·범례·날짜·두 곡선·조건·가정·모형판·교육용 표시 포함),
  CSV(UTF-8 BOM, 0일 포함 날짜별 S/E/I/R·새 감염·누적, 머리에 메타데이터 주석),
  설정 JSON 저장·불러오기.
- **고급 가정 패널** — 코드에 숨어 있던 백신 효과·추적 효과 0.9 를 화면으로 꺼냈다.
  역산 실험도 같은 값을 쓴다. 숨은 상수는 남아 있지 않다.

## 5. 고친 표현

| 전 | 후 |
|---|---|
| ‘전염의 몇 %가 증상 전’ | ‘격리가 손대지 못하는 전염 기간의 몫’ + 하루 전염력이 같다는 가정 명시 |
| ‘한 값으로 10년이 맞는다’, ‘유효 면역 수준’ | ‘이 모형 안에서만 뜻이 있는 수’, 실제 접종률·면역 수준으로 부르지 않음 |
| 면역 임계치 = 유행이 스스로 멈추는 선 | 고르게 섞인다는 가정의 값이며 목표 접종률·종료 보장이 아님 |
| 메르스 → “검역이 관건” | 모형의 한계를 적고 일률적 정책 결론을 뺌 |
| ‘정점은 실제보다 높고 이르다’ | ‘다를 수 있다. 어느 쪽으로 얼마나인지는 확인한 적 없다’ |
| ‘접종률’ | ‘보호 비율(접종 가정)’ + 백신 존재·대상·효과는 확인하지 않았음을 적음 |

## 6. 확인하지 못한 것 — 값을 바꾸지 않고 남긴다

`모형_매개변수.json` 의 `_check` 에 같은 내용이 들어 있고 화면 ‘출처’ 절에도 표로 나온다.

1. **풍진 `d_inf=11`** — 같은 항목의 설명은 ‘발진 7일 전~7일 후’(14~15일)다. 서로 맞지 않는다.
   어느 쪽이 맞는지 공식 출처를 확인하지 못했으므로 **값을 그대로 두었다.**
2. **백신 효과·추적 효과 0.9** — 질환별 근거가 없다. 교육용 가정으로 표시만 했다.
3. **15종의 접종 적용 가능성** — 각 병에 실제 백신이 있는지·대상이 누구인지·감염을 얼마나
   막는지 확인하지 않았다. 손잡이 이름과 안내로만 구분했다.
4. **R₀·전염 기간·증상 전 전염 일수** — 기존 문헌 표기를 그대로 두었다. 원문 표와 입력값의
   대응을 이번에 새로 대조하지 않았다.
