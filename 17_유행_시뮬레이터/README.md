# ⑰ 유행 시뮬레이터 — "격리를 하루 늦추면 얼마나 달라지나"

> 🔗 <https://soonryu74.github.io/disease/sim/>

감염병Lab의 둘째 갈래. 병마다 **도감의 잠복기**, **문헌의 R₀ 범위**, **증상 전 전염 일수**를 넣고 SEIR 모형을 돌린다. 격리 시점·격리 효과·접촉자 추적·접종률을 두 시나리오로 나란히 놓는다.

## 이 페이지의 주장

답은 숫자가 아니라 **어느 손잡이가 이 병에 듣는가**다.

| 병의 성질 | 예 | 듣는 손잡이 |
|---|---|---|
| 증상 뒤에 전염이 집중 | SARS · 에볼라 · MERS | **빠른 격리**. 2003년 SARS 종식이 가능했던 이유 |
| 증상 전 전염이 큼 | 풍진(7/11일) · 폴리오 · 코로나19(2/8일) | 격리는 늦다. **접촉자 추적·접종** |
| R₀가 큼 | 홍역 12–18 · 백일해 12–17 | 격리로 R을 1 밑으로 못 내린다. **접종률 ≥ 1−1/R₀** |
| R₀ < 1 | MERS(지역사회) · 니파 | 스스로 잦아든다. **유입을 막는 검역**이 관건 |

모형이 계산하는 "격리가 못 건드리는 전염" = (증상 전 일수 + 격리 지연) ÷ 전염 기간. 이 하나의 비율이 위 표를 만든다.

## 수록 (15종 — 사람 사이 직접 전파되는 것만)

`data/모형_매개변수.json`: 홍역·백일해·수두·유행성이하선염·풍진·디프테리아·폴리오·인플루엔자·신종인플루엔자·코로나19·SARS·MERS·에볼라·엠폭스·니파. 각각 R₀ 범위(출처)·전염 기간·증상 전 전염 일수·메모.

잠복기와 전파경로는 ⑤ 도감에서 읽는다. 도감이 대표값을 못 주는 3종(코로나19 항목 없음 · SARS "KDCA 미명시" · MERS "최대 14일"만)은 WHO 값을 쓰고 그 사실을 화면에 적는다.

## 모형

이산 시간 SEIR(dt = 0.25일). 잠재기 = 잠복기 대표값 − 증상 전 전염 일수(최소 1일).

- β = R₀ / D · f_격리 · f_추적
- f_격리 = c + (1 − c)(1 − e), c = min(증상 전 + 지연, D) / D, e = 격리 효과
- f_추적 = 1 − (추적률 × 0.9)
- S₀ = N (1 − 접종률 × 0.9)
- R_eff(0) = R₀ · f_격리 · f_추적 · S₀/N

## 이 모형이 말하지 않는 것

균질 혼합(연령·가정·병원 구조 없음), R₀는 범위, 잠복기≠잠재기 근사, 행동 변화 없음(정점이 실제보다 높고 이름), 무증상 감염 별도 없음. **정책 근거가 아니다.** 손잡이 사이의 관계를 눈으로 익히는 도구다.
