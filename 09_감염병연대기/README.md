## 왜 이게 "세상에 없는" 것인가

"매독은 몇 급인가요?"라는 질문에는 답이 없다. **2019년의 매독은 제3군 전수감시, 2021년엔 제4급 표본감시, 지금은 제3급 전수감시**다. 이름도(원숭이두창→엠폭스, 나병→한센병), 급수도, 세는 방법도 계속 바뀌었다.

- 법제처는 법령의 시점별 버전을 갖고 있지만 **질병 사실과 연결하지 않는다**
- 질병관리청은 현재 사실을 갖고 있지만 **과거 시점을 조회할 수 없다**
- 이 플랫폼은 그 시간축을 통째로 들고 있어서, **날짜를 대면 그 시점의 사실**을 돌려준다

⑦ 토론 5위 인사이트("시점 미인지 검색은 폐지된 신고기준을 정답으로 반환한다")를 플랫폼 전체의 설계 원리로 승격한 것이다.

## 설계 원칙 (양보 불가)

1. **시점 없는 사실은 없다.** 모든 필드는 국면(from~to)에 속한다.
2. **모르면 빗금.** 원문 대조 전 구간은 `미정리`로 표기하고 절대 추정하지 않는다. (한센병 1954~2019, 쯔쯔가무시증 군 체계 시기 등)
3. **연도 경고 동봉.** 부분연도·범위 변경이 있는 해는 사실 카드에 "이 해 통계를 읽을 때" 경고가 붙는다.
4. **모든 카드에 근거.** 법률 공포일·고시 번호·연보 각주.

### 빌드
```bash
python3 - <<'EOF'
import json
db=json.load(open('09_감염병연대기/data/연대기.json',encoding='utf-8'))
t=open('09_감염병연대기/연대기.template.html',encoding='utf-8').read()
d=json.dumps(db,ensure_ascii=False,separators=(',',':')).replace('</','<\\/')
open('09_감염병연대기/연대기.html','w',encoding='utf-8').write(t.replace('__DATA__',d))
EOF
```

## 한계 (정직하게)

- 자동 79종의 군 국면은 '2020 개편 직전 기준'이라 2010~2019년 사이 군 변동(예: 폐렴구균 2014.9 지정)이 뭉개져 있다 — 카드 각주로 명시했고 v1.5에서 정밀화한다.
- 월 단위 해상도다 — 같은 달 안의 변경(예: 2023.8.31)은 그 달 전체로 표시된다.
- 군 체계 이전(1954~2000) 국면은 대부분 미정리다. 이 구간의 원문 대조가 가장 큰 확장 과제다.
