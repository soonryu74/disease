# ⑧ 감염병 통계 단절점 검사기

> **"이 수치, 작년과 비교해도 되나요?"** — 질병과 두 연도를 고르면 비교해도 되는지, 안 된다면 왜인지를 판정한다.
> 🔗 **도구 열기**: <https://claude.ai/code/artifact/bcbf2999-af6b-45a0-9f20-4d2504ddeb50>
> 원본: [`단절점_검사기.html`](./단절점_검사기.html)

---

## 왜 만들었나

§01~⑦에서 만든 것 대부분은 **정부가 이미 무료로 공개한 자료를 모은 것**이다. 모아놓은 것만으로는 쓸모가 제한된다.

우리만 가진 것은 하나다 — **단절점 원장**. "이 숫자를 저 해 숫자와 비교해도 되는가"에 답하는 자료.
조각은 연보 각주에 있지만 **한 곳에 모여 있지 않다**. 2016년 B형간염 각주는 2016년 연보에, 2019년 VRSA 각주는 2019년 연보에 묻혀 있다.

그리고 **이 공백이 실제로 피해를 만든다**:
- 언론이 "2024년 매독 2,790명 폭증"으로 보도했고 → **질병관리청이 보도설명자료를 냈다**(2024.4.22)
- 정부가 해명 자료를 낼 정도면 실재하는 오독이다
- 2025년 쯔쯔가무시증 △45.7%도 똑같이 "방제 성과"로 읽힐 준비가 돼 있다 (실제로는 **가피 판정기준 추가** 때문)

이 도구는 그 오독을 **묻기 전에** 막는다.

## 무엇을 하나

| | |
|---|---|
| **판정** | 🟢 비교 가능 / 🟡 비교 가능하나 해석 주의 / 🔴 비교 불가 |
| **이유** | 걸리는 단절점을 날짜·근거 법령·영향과 함께 제시 |
| **대안** | 동일 신고범위로 재계산한 값을 제시 (가능한 질병) |
| **각주** | 보고서·기사에 그대로 붙여 쓸 문장을 생성 |
| **그래프** | 단절점에서 **선을 실제로 끊어** 그린다 — 이어서 읽으면 안 되는 곳이 눈에 보인다 |

### 판정 규칙

두 연도 사이(min < 단절연도 ≤ max)에 걸리는 항목으로 판정한다.

- **`break` (정의 변경) → 🔴 비교 불가** — 급수·감시체계·신고범위·진단기준이 바뀌어 **세는 대상이나 세는 기관이 다르다**. 증감률을 계산하면 유행이 아니라 제도 변경을 측정한다.
- **`caution` (맥락 변경) → 🟡 해석 주의** — 정의는 같아 수치를 나란히 둘 수는 있으나 기저가 다르다. (급 체계 개편 2020.1.1, 코로나19 NPI 구간 2020~2022, 명칭 변경 등)
- **둘 다 없음 → 🟢 비교 가능**

### 결측('-')을 세 가지로 구분한다 — 이게 핵심 설계

같은 빈칸이지만 뜻이 전혀 다르고, 구분하지 않으면 판정이 틀린다.

| 사유 | 뜻 | 예 |
|---|---|---|
| `not_notifiable` | 법정감염병이 아니었다. **0건이 아니라 세지 않았다** | E형간염 2019, 니파 2024 |
| `sentinel` | **표본감시라 전수표에 없다.** 자료가 없는 게 아니라 분모가 다르다 | 매독 2020~2023(572개소), 코로나19 2024~ |
| `moved` | 같은 병이 **다른 급 행에 실려 있다** | 코로나19 2020~2021(신종감염병증후군 행) |

> 초기 버전은 이 셋을 뭉뚱그려 매독 2023↔2024를 "자료가 없다"로 판정했다. 가장 중요한 사례를 정확히 틀리게 답한 것이다. 지금은 "2023년은 표본감시 구간"이라 답하고 **2019↔2024 동일범위 비교(1,753 → 1,519, △13.3%)** 를 대신 제시한다.

### 대체 연도는 시간 순서를 지킨다

고른 해에 동일범위 값이 없으면 가장 가까운 유효 연도로 바꾸되, **상대 연도의 반대쪽에서만** 찾는다.
2023(기준) ↔ 2024(비교)에서 2023을 2025로 바꾸면 앞뒤가 뒤집히므로 2019로 간다.

### 갱신 방법
```bash
python3 08_비교가능성_검사기/build_rules.py      # 규칙 JSON 재생성
python3 - <<'EOF'                                  # 데이터 주입 → 배포본

EOF
```

## 한계 (정직하게)

- **제4급(표본감시) 23종은 없다.** 분모가 질병마다 달라 같은 표에 놓을 수 없다. 인플루엔자·수족구 등을 보려면 별도 축이 필요하다.
- **연 단위다.** 주·월 단위 중단시계열 분석은 감염병포털 동적 통계가 필요한데 현재 접근이 막혀 있다.
- **동일범위 재계산은 매독만 있다.** 다른 질병은 병기·세부 항목별 원자료를 아직 확보하지 못했다.
- **2016년 이전은 없다.** 연보 붙임4가 10년치만 싣는다. 그 이전은 과거 연보를 개별 확보해야 한다.
- 단절점은 **연보 각주와 고시 이력에서 확인된 것만** 등재했다. 각주에 적히지 않은 운영상 변경은 잡히지 않는다.
