## A. 백서 9판 원문 유실 (2004~2011, 2014~2015)

### 무엇이 발견됐나
게시판 HTML 소스에 해당 연도 항목이 **`<!-- ... -->` 주석으로 감싸져** 있다. 화면에는 2012~2024만 보인다.

```html
<!--li><img src="/sites/kdca/images/sub/whitepaper2014~2015(kor).jpg" alt="">
<p>2014~2015년 질병관리백서</p>
<a href="/sites/kdca/download/">다운로드</a> </li-->
```

`href`가 `/sites/kdca/download/` — **파일명이 비어 있다**. 주석을 풀어도 내려받을 수 없다.

### 실재 여부 검증
표지 이미지 URL을 직접 조회한 결과 **전부 HTTP 200**:

| 연도 | 표지 이미지 | 결과 |
|---|---|---|
| 2004 | `whitepaper2004(kor).jpg` | ✅ 200 (5,970 B) |
| 2005 | `whitepaper2005(kor).jpg` | ✅ 200 (6,003 B) |
| 2006 | `whitepaper2006(kor).jpg` | ✅ 200 (5,953 B) |
| 2007 | `whitepaper2007(kor).jpg` | ✅ 200 (8,088 B) |
| 2008 | `whitepaper2008(kor).jpg` | ✅ 200 (6,001 B) |
| 2009 | `whitepaper2009(kor).jpg` | ✅ 200 |
| 2010 | `whitepaper2010(kor).jpg` | ✅ 200 (6,634 B) |
| 2011 | `whitepaper2011(kor).jpg` | ✅ 200 |
| 2014~2015 | `whitepaper2014~2015(kor).jpg` | ✅ 200 |

→ **해당 백서들은 실제로 발간되었고 누리집에 게시된 적이 있다.** 표지 이미지는 남았고 본문 PDF만 사라졌다.

추정 파일명 직접 조회는 모두 404:
`2014-2015질병관리백서.pdf` · `2014+질병관리백서.pdf` · `2014~2015+질병관리백서.pdf` · `2010+질병관리백서.pdf` → **404**
(살아 있는 파일은 `2012+질병관리백서.pdf`처럼 동일 규칙을 따르므로, 명명 규칙 문제가 아니라 **파일 부재**다.)

### 왜 중요한가

이 9판은 **한국 감염병사의 핵심 구간을 통째로 덮는다**:

| 유실 판 | 그 시기의 사건 |
|---|---|
| 2004~2008 | 질병관리본부 설립 초기, **사스(2003) 직후 체계 구축**, 조류인플루엔자 대응 |
| **2009·2010** | ⭐ **신종플루 H1N1pdm09 대유행** — 국내 발생률 10만 명당 1,502.6명(2024 백서 인용). 2020년 이전 최대 감염병 사건의 1차 사료 |
| 2011 | ⭐ **결핵 최고치 50,491명(10만 명당 100.8명)** — 이후 13년 감소의 기준점 |
| **2014~2015** | ⭐ **메르스 유행(확진 186·사망 38)** 당해 연도를 수록하는 판 |

즉 **신종플루·메르스·결핵 정점**이라는 세 개의 기준점이 모두 접근 불가 구간에 있다.
2016년판이 메르스를 회고하지만, **당해 연도 기록과 사후 회고는 사료로서 값이 다르다**.

> §04 사업화 관점: 이건 리스크가 아니라 **공백**이다. 정부 원문이 사라진 자리를 메우는 아카이브는 그 자체로 자산이 된다.

### 복구 후보 경로 (미착수)
- 국가기록원 / 국회도서관 소장본
- 정책연구관리시스템(PRISM)·공공데이터포털
- 웹아카이브(국립중앙도서관 OASIS, Internet Archive)의 과거 누리집 스냅샷
- 질병관리청 정보공개청구

## B. 2022년 백서[영문] 링크 오류

```
2022년 질병관리청 백서[영문] → /sites/kdca/download/2023+질병관리청+백서[영문].pdf
2023년 질병관리청 백서[영문] → /sites/kdca/download/2023+질병관리청+백서[영문].pdf   (동일)
```

**두 항목이 같은 파일을 가리킨다.** 2022 영문판을 내려받으면 2023 영문판이 온다.
이전 판에서 "오기 추정"으로 적었던 항목을 **소스 대조로 확정**했다.

## C. PDF 텍스트 추출 불가 (2020-2021 · 2022 · 2023 · 2024)

`pypdf`로 각 PDF 표본 6페이지를 추출한 결과:

| 파일 | 크기 | 페이지 | 추출 결과 |
|---|---|---|---|
| 2020-2021.pdf | 84 MB | 453 | 페이지당 **12자**(쪽번호만) — 사실상 이미지 |
| 2022.pdf | 198 MB | 429 | `/g21/g22/g24...` 글리프 번호 |
| 2023.pdf | 63 MB | 405 | `/g20/g20/g27...` 글리프 번호 |
| 2024.pdf | 181 MB | 415 | `/g12804/g23/g16213...` 글리프 번호 |

원인: 본문 글꼴이 **ToUnicode CMap 없이 서브셋 임베드**되어 있다. 화면에는 정상 표시되지만 기계가 글자로 읽을 수 없다.
2020-2021판은 아예 스캔 이미지에 가깝다.

**영향**: 검색·인용·RAG·번역 모두 불가. **웹 접근성(스크린리더) 관점에서도 문제**다.
**우회**: 2024년판은 별도 제공되는 **텍스트 대체자료(txt)** 로 해결. 나머지는 OCR 필요.

> 질병관리청이 2024년판부터 텍스트 대체자료를 제공하기 시작한 것은 **개선**이다. 소급 적용이 남은 과제다.

## D. 2024 텍스트판의 부록 결락

원문 말미 제작자 주:

> *"대체자료로 제작된 파일은 「2024 질병관리청 백서 제1, 2권」으로 「제3권 부록」에 해당하는 내용은 없음."*

빠진 제3권에는 **국가승인통계 14종**이 들어 있다 — 국민건강영양조사, **법정감염병발생보고**, HIV/AIDS신고현황, 결핵환자신고현황, 전국어린이예방접종률현황, 국가관리대상 희귀질환 현황, 심뇌혈관질환 발생통계 등.

즉 **본문 서술은 텍스트로 읽히지만, 통계 원표는 여전히 PDF에 갇혀 있다.**
→ 우리의 시계열 통계 작업(`시계열_통계.csv`)은 여기서 막힌다. 대안은 [감염병 신고 현황 연보](https://dportal.kdca.go.kr) 별도 확보.
