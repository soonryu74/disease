# ③ 질병관리청 백서 정리

질병관리청(구 질병관리본부)이 연도별로 발간하는 **백서**의 통합 인덱스. 백서는 청의 정책 추진 방향·성과(감염병 관리, 위기대응, 보건의료 R&D 등)를 종합 기록한 1차 사료다.

- 공식 백서 게시판: <https://www.kdca.go.kr/kdca/2873/subview.do>
- 공공데이터포털(파일데이터): <https://www.data.go.kr/data/15004347/fileData.do>

## 2. 백서 표준 정리 템플릿 (권별)

각 백서를 아래 표준 서식으로 1장씩 정리하면 검색·비교가 쉬워진다.

```markdown
### {연도} 질병관리청 백서
- 발간기관 / 발간일 / 총 페이지 / ISBN(있으면)
- 다운로드: {URL}
- 목차(대분류):
- 그해의 핵심 이슈(감염병 사건·정책):
- 주요 통계 수치:
- 전년 대비 달라진 점:
- 인용 시 출처표기:
```

## 3. 수집·정리 방법 (재현 가능)

1. 게시판 목록 페이지에서 각 연도 게시글 링크 수집
2. 첨부 PDF 다운로드 → `data/{연도}/` 에 원본 저장
3. PDF 목차·요약 추출(스킬 `pdf` 활용)하여 위 템플릿으로 요약본 작성
4. 연도 간 통계(감염병 발생·예방접종률 등) 시계열로 통합 → `03_백서_정리/시계열_통계.csv`

> 백서 PDF는 대용량이라 원문은 저장소에 커밋하지 않고 **요약본 + 원본 링크**로 관리하는 것을 권장한다.
