## 1. 본문 요약 진행 현황

| 판 | 본문 요약 | 근거 |
|---|---|---|
| **2024** | ✅ **완료** → [`2024_백서_본문요약.md`](./2024_백서_본문요약.md) | 공식 **텍스트 대체자료(txt) 전문** 대조 |
| 2023 · 2022 · 2020-2021 | ⏸ 보류 | PDF 확보(63~198 MB)했으나 **폰트 인코딩 문제로 텍스트 추출 불가** — OCR 필요 |
| 코로나19 대응 백서 | ⏸ 미착수 | 별도 게시물 경로 확인 필요 |
| 2019 이하 | ⏸ 미착수 | 동일 추출 문제 예상 |

> **왜 2024만 되는가**: 질병관리청은 **2024년판에만** 시각장애인용 텍스트 대체자료(txt)를 제공한다. 나머지는 '펼침(spread)' PDF이고, 본문 글꼴이 ToUnicode 매핑 없이 서브셋 임베드되어 있어 텍스트 추출 시 글리프 번호(`/g1171` 등)만 나온다. 실측 확인 완료(pypdf, 2022·2023·2024 PDF 각 6페이지 표본).

## 2. 유의사항 (검증 완료 / 미검증 구분)

**✅ 실측 확인됨**
- 2004~2011·2014~2015 백서는 **실재했다** — 누리집에 표지 이미지(`whitepaper2004(kor).jpg` 등)가 HTTP 200으로 살아 있다. 다만 화면 노출과 파일 링크가 끊겼다.
- **2022년 백서[영문] 링크가 2023년 영문 PDF를 가리킨다** (`2023+질병관리청+백서[영문].pdf`). 링크 오류 확정.
- 2024년판 텍스트 대체자료는 **제1·2권만** 수록. **제3권 부록(국가승인통계 14종)은 텍스트판에 없다** — 원문 제작자 주에 명시.

**❓ 미확인**
- 2012~2019 각 백서의 영문·텍스트판 존재 여부(현 목록상 국문만).
- 각 백서의 **정밀 수록기간**(백서명 연도 ≠ 활동연도).
- 2004~2011 원문의 국회도서관·국가기록원 소장 여부.

**📌 구분해야 할 것**
- **「2015 메르스 백서」(2016.7)** 는 **보건복지부·한국보건사회연구원** 발간으로, 질병관리청 백서와 **별개 간행물**이다.
