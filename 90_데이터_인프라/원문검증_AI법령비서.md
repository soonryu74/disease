# 원문 검증 로그 & 'AI 법령비서' 확인 결과

## 1. 'AI 법령비서'는 우리가 쓸 수 없다 (공무원 전용)

2026.7.14 법제처·행안부·과기정통부가 공동 개시한 **'AI 법령 비서'** 를 확인한 결과:

| 항목 | 내용 |
|---|---|
| 대상 | **공무원 전용** (중앙·지방 공무원) |
| 접속 | **행정내부망**의 'AI 대화서비스 온AI 실험실'에서만 |
| 외부/일반인 접속 | ❌ 불가 (공개 웹·공개 API 없음) |
| 데이터 | 법령·행정규칙 24만 건 + 대법원 판례 6만 건 RAG |
| 모델 | 범정부 AI 공통기반의 독자 파운데이션 모델 |

→ **외부 AI(나)도, 일반 국민도 접속·검색 불가.** 따라서 이 서비스로 검증하는 것은 불가능하다.

### 일반인이 쓸 수 있는 공개 대체재
1. **법제처 국가법령정보 Open API** — 우리가 이미 사용 중(원문 근거). ⭐ 검증의 기준.
2. **법제처 Lawbot(지능형 법령검색)** — <https://www.law.go.kr/LSW/aai/main.do> (공개 AI 법령검색)
3. AI법령비서와 **같은 데이터 원천(법령정보 RAG)** 을 우리도 API로 직접 쓰므로, 사실 검증력은 동등하거나 더 투명하다(출처 링크 100%).

## 2. 원문 검증 결과 — 우리가 쓴 내용은 법령 원문과 일치

**방법**: `lawService.do?target=law&MST=280445&type=XML` 로 **현행 감염병예방법 전문(시행 2026.6.24, 공포 제21234호, 139개 조문)** 을 받아 조문 단위로 대조.

| 우리 서술(§01 조항별 분석) | 원문 확인 | 판정 |
|---|---|---|
| 격리·입원 위반 = 1년 이하 징역/1천만원 | 제79조의3, [본조신설 2020.3.4] | ✅ 일치 |
| 역학조사 거부 = 2년 이하 징역/2천만원 | 제79조(제18조제3항), 개정 2015.7.6 | ✅ 일치 |
| 제1·2급 신고위반 = 500만원 | 제79조의4 | ✅ 일치 |
| 제3·4급 신고위반 = 300만원 | 제80조 | ✅ 일치 |
| 정보공개 개인정보 보호(성별·나이 제외, 삭제의무) 신설 | 제34조의2 단서·②항, [신설 2020.9.29] | ✅ 일치 |
| 손실보상 확대 | 제70조, 개정 2015.12.29 외 | ✅ 일치 |

→ **핵심 주장 6건 모두 현행 원문과 일치.** 조문 제목·개정일까지 확인.

### 참고: 조문 전문 조회 방법(재현)
```
# 현행 전문(조문 단위 XML) — type=XML 이 핵심
https://www.law.go.kr/DRF/lawService.do?OC=test&target=law&MST=280445&type=XML
```
> `type=HTML` 은 iframe 껍데기만 오지만, **`type=XML` 은 조문단위 구조화 데이터**가 온다. 조항별 개정 추적에 이 방식을 쓴다.
