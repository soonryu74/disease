## 3. 권고안 — "1주소 원칙"

### A안: 신규 Vercel 프로젝트 (예: `disease-hub`) + GitHub repo 단일 소스

```
disease-hub.vercel.app          ← 유일한 마스터 주소 (이것만 기억·공유)
├── /            통합 허브 (현 아티팩트 이식)
├── /daily       ★ 오늘의 상황판 — 같은 경로 덮어쓰기
├── /daily/2026-08-15 …         날짜별 아카이브 자동 누적
├── /law         감염병예방법 70년 (이식)
├── /flu         인플루엔자 감시 100년 (이식)
└── /docs        지식베이스(GitHub 연결)
```

**운영 규칙 3가지**
1. **모든 완성물은 repo에 커밋** → Vercel 자동 배포 (첨부 금지)
2. **데일리 안내 메시지는 링크 한 줄**: "오늘 상황판 → disease-hub.vercel.app/daily" (링크가 항상 같으므로 사실상 안내도 불필요해짐)
3. **claude.ai 아티팩트는 제작 프리뷰용으로 강등** — 마스터는 항상 포털

**왜 이게 되나**: 우리 산출물(허브·연혁·인플루엔자·상황판)은 전부 **의존성 없는 정적 HTML** → 파일 복사만으로 이식 완료. Vercel은 이미 쓰고 계셔서 추가 비용·학습 없음.

### 데일리 파이프라인 (상황판 만드는 세션에 지시 1줄 추가)
> "완성된 상황판 HTML을 `soonryu74/disease` repo `portal/daily/index.html`(+ `daily/YYYY-MM-DD.html`)로 커밋·푸시해줘"
→ push 즉시 자동 배포, 링크 불변, 아카이브 자동 누적.
