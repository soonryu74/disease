# 법제처 국가법령정보 공동활용 Open API — 활용 가이드

> "대한민국 법률을 모두 정리한 API가 있다는데 그걸로 가능한지, 연도별은 또 다른 건지"
> 에 대한 정리. **결론: 가능하다. 그리고 '연도별(연혁)'은 별도 target(엔드포인트)이다.**

---

## 1. 무엇인가

- **정식 명칭**: 국가법령정보 공동활용 Open API (법제처)
- **포털**: <https://open.law.go.kr>
- **요청 기본 URL**: `https://www.law.go.kr/DRF/`
  - 목록조회: `lawSearch.do`
  - 본문조회: `lawService.do`
- **비용**: 무료
- **인증**: `OC` 파라미터(발급받은 이메일 ID). 공식 가이드의 공개 **테스트키 `OC=test`** 로도 일부 기능(현행법령·시행일법령)은 즉시 호출된다.
- **응답 형식**: `type=XML | JSON | HTML`

### 인증키(OC) 발급 절차
1. <https://open.law.go.kr> 회원가입/로그인
2. [OPEN API] → [OPEN API 신청] 메뉴
3. 사용할 API 종류(법령/연혁법령/행정규칙/자치법규/판례 등)를 **각각 체크**하여 신청
4. 승인 후 본인 이메일 앞부분이 `OC` 값이 됨 (예: `hong@korea.kr` → `OC=hong`)

> ⚠️ 신청하지 않은 API를 호출하면 `"미신청된 목록/본문에 대한 접근입니다"` 에러가 난다.
> (실제로 `OC=test`로 연혁 전용 API를 부르면 이 에러가 발생함 → 본인 OC로 해당 API를 신청해야 함.)

---

## 2. 핵심: 현행법령 vs 연도별(연혁)은 target이 다르다

| 목적 | target | 반환 | OC=test 동작 |
|---|---|---|---|
| **현행법령** (지금 시행 중 1건) | `law` | 최신 시행 버전 1건 | ✅ 됨 |
| **연도별(시행일 기준) 과거·예정 버전 전체** | `eflaw` | 시행일마다 별도 버전(각각 고유 `MST`) | ✅ 됨 |
| **법령 연혁 전용 목록** | `lsHistory` | 제·개정 연혁 목록 | ❌ 본인 OC 신청 필요 |
| 법령 변경이력 | `lsHstInf` | 변경이력 | 본인 OC 신청 필요 |

**정리**
- "지금 법" 한 건만 필요 → `target=law`
- **"1954년부터 연도별로 어떻게 바뀌었나" → `target=eflaw`** (또는 `lsHistory`)로 **별도 조회**한다.
- 각 버전은 `법령일련번호(MST)`가 다르며, `공포일자·공포번호·시행일자·제개정구분(제정/일부개정/전부개정/타법개정)`을 갖는다.

## 3. 실제 검증된 호출 예시

### (1) 현행법령 검색 — 법령ID 찾기
```
https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=law&query=감염병&type=XML
```
→ 감염병의 예방 및 관리에 관한 법률 = **법령ID `001792`**, 약칭 "감염병예방법"

### (2) 연도별(시행일) 전체 연혁 — 이 프로젝트의 핵심
```
https://www.law.go.kr/DRF/lawSearch.do?OC=test&target=eflaw&query=감염병의 예방 및 관리에 관한 법률&type=XML&display=100&page=1
```
→ 법률 67개 버전(제정 1954 → 현행 2026) 전부 수집됨. 같은 방식으로 시행령·시행규칙도 수집.

### (3) 특정 시점 본문 조회
```
https://www.law.go.kr/DRF/lawService.do?OC=test&target=eflaw&MST=<법령일련번호>&type=HTML
```
→ 그 버전의 조문/부칙/별표 전문.

## 5. 주의 · 한계
- `OC=test`는 공용 테스트키라 호출량이 많으면 제한될 수 있음 → 본인 OC 권장.
- 별표·서식 이미지는 별도 다운로드 URL로 제공.
- 지침·백서는 **법령이 아니므로 이 API 대상이 아님** → 질병관리청 사이트/공공데이터포털 별도 수집(§ 02, 03 참고).
