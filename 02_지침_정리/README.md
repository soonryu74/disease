# ② 감염병 관련 지침 정리 (질병관리청 발간)

질병관리청이 발간하는 **감염병 관리지침**의 통합 인덱스 + 품질검수(오탈자 등) 체계.
지침은 법령(§01)과 달리 매년 갱신되는 실무 문서로, 감염병별·시설별·상황별로 다수 존재한다.

> 📋 **지침 인덱스**: [`지침_마스터목록.md`](./지침_마스터목록.md) (대분류별 25종+, 2026년판 포함)
> 📊 **전량 크롤링**: [`data/지침_전체목록_감염병포털.csv`](./data/지침_전체목록_감염병포털.csv) (358건, 2002~2026)
> ✅ **품질검수 리포트**: [`검수_리포트.md`](./검수_리포트.md) (실오류 1건 발견 — SFTS 병명 오기)

## 공식 출처 (1차)
- **질병관리청 지침 게시판**: <https://www.kdca.go.kr/menu.es?mid=a20507020000>
- **감염병포털 감염병지침**: <https://dportal.kdca.go.kr/pot/bbs/BD_selectBbsList.do?q_bbsSn=1001>
- 코로나19 지침(별도): <https://www.kdca.go.kr/kdca/2862/subview.do>

## 1. 지침 분류 체계 (인덱스 골격)

| 대분류 | 예시 지침 | 갱신 주기 |
|---|---|---|
| **호흡기 감염병** | 코로나19 관리지침, 인플루엔자(시설별) 관리지침, 결핵 관리지침 | 연 1회+수시 |
| **인수공통감염병** | 브루셀라증·공수병·큐열·SFTS 관리지침 | 연 1회 |
| **수인성·식품매개** | 콜레라·장티푸스·A형간염 등 관리지침 | 연 1회 |
| **매개체 감염병** | 말라리아·일본뇌염·쯔쯔가무시증 관리지침 | 연 1회 |
| **의료관련감염** | 의료관련감염병 관리지침, 항생제내성(CRE 등) | 연 1회 |
| **예방접종** | 예방접종 대상 감염병 관리지침, 표준 예방접종 일정 | 연 1회 |
| **신고·감시** | 법정감염병 진단·신고 기준, 감염병 감시연보 | 연 1회 |
| **위기대응** | 감염병 위기관리 표준매뉴얼, 생물테러 대응지침 | 수시 |

> 각 지침은 `data/{대분류}/{지침명}_{발간연도}.pdf` 로 원본을, `요약/{지침명}.md` 로 요약을 관리.

## 3. 품질 검수 체계 — "오타 등도 걸러내기"

지침 텍스트를 수집한 뒤 아래 자동/수동 검수를 적용한다.

### 3-1. 자동 검수 (스크립트)
- **맞춤법/오탈자**: 한국어 맞춤법 검사(예: `hanspell`/부산대 맞춤법 검사기 연동) → 의심 목록 산출
- **표기 일관성**: 같은 용어의 혼용 탐지
  - 예) `전염병 ↔ 감염병`, `제1군 ↔ 제1급`, `코로나바이러스감염증-19 ↔ 코로나19 ↔ COVID-19`
- **법정 급수 오기**: 지침이 인용한 급수/신고기한이 현행 법령(§01)과 불일치하는지 대조
- **깨진 링크·구법 인용**: 폐지·개정 전 조문 인용 여부 점검
- **수치 정합성**: 잠복기·격리기간 등 지침 간 상충 탐지

### 3-2. 검수 산출물
- `검수/오탈자_후보.csv` — (지침명, 위치, 원문, 제안, 판정)
- `검수/용어_비일관.csv`
- `검수/법령_불일치.csv`

> ⚠️ 자동 검수는 **후보 제시**까지만. 최종 판정은 사람이 하고, 원문 인용 시 반드시 원본 표기를 유지한다(공문서 수정 아님).
